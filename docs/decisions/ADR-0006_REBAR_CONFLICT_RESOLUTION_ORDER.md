# ADR-0006：梁配筋冲突按 ETABS 读取值、安全与施工便利性分层裁决

## Context

梁配筋引擎同时面对 ETABS 需求结果、ETABS 已提供面积、ACI 最低构造、SMF 容量设计、可放置几何和项目偏好。若直接按“根数最少”或“某个优选直径”选方案，可能在不明显报错的情况下减少已确认的 ETABS 配筋，或以大直径少根数换来梁柱节点拥挤。

本 ADR 只定义将来算法的裁决顺序和失败动作；它不修改当前钢筋、不修改 ETABS 模型，也不把未完成的精确节点排布当成施工图设计。因 `20d_b`、容量剪力取值和“已提供面积是否作为自动保留基线”仍须由结构工程师确认，本 ADR 在批准前为 `proposed`。

## Decision

候选方案按下列门禁顺序裁决。低层门禁未通过时，不得以高层的便利性、统一直径或节省钢筋覆盖。

| 顺序 | 门禁/目标 | 冲突解决办法 | 不满足时的动作 |
|---:|---|---|---|
| G0 | **数据可信度** | 先确认 ETABS 产品/版本、模型身份、单位、设计状态、Frame Type、组合、站点和 API error。`PARTIAL`、空结果、错误数组、未知单位、结果过期或 SMF 体系来源不明均不是可自动设计输入。 | `BLOCKED` / `REVIEW_REQUIRED`；保留原始值和原因。 |
| G1 | **读取值与强度下限** | 每个区段分别以已确认 ETABS `required` 面积/剪力/扭矩为下限；再与 ACI 最小配筋、抗扭、SMF `Vc=0` 容量剪力等下限取控制值。不同站点、不同组合的各作用可独立包络，但输出必须保留每个作用的控制站点和组合，不能把它们标成同一组合。 | 没有满足全部下限的候选时 `NO_ALLOWED_LAYOUT` / `SECTION_RESIZE_REQUIRED`，不得减小需求。 |
| G1a | **ETABS 已提供面积的自动保留** | 在 G0 已确认且 ETABS 给出有效 `provided` 值时，默认运行模式不得自动把纵筋面积降到该值以下；最终面积下限为 `max(required, provided, code minimum)`。`-1`、空值或未确认结果不伪造为零，而是 `ETABS_PROVIDED_UNAVAILABLE`。经结构工程师明确启用的“复核优化”模式才可减小已提供面积，并必须保留对比和签认。 | 无法保留时输出复核草稿并阻断“自动采用”；不可静默改小或替换为低配方案。 |
| G2 | **规范与抗震安全** | 逐候选复核最终布置的截面强度、最大钢筋率、连续筋、SMF 正负强度比例、实际箍筋坐标/间距、`2h`、首箍、容量剪力、锚固/接头禁区及 `20d_b`。`20d_b` 必须使用**沿该梁方向的柱实际尺寸**和**穿过节点的最大梁主筋直径**；不得误用 `6d_b` 的最小纵筋直径。容量剪力必须在选择箍筋前成为横筋需求，不能只作为事后提示。 | `BLOCKED_CODE_MINIMUM`、`SMF_JOINT_DEPTH_UNRESOLVED`、`SMF_JOINT_DEPTH_FAILED` 或其他可追溯状态；优先调整截面或钢筋方案。 |
| G3 | **可放置与施工顺序** | 仅在 G1/G2 均通过的候选中检查保护层、净距、层数、箍筋/拉筋对纵筋的约束、节点内 X/Y 梁筋与柱筋的空间、锚固可用长度和浇筑通道。共同支座或相邻跨协调改变任何一跨的钢筋、直径或层数后，必须重新执行 G1～G3，不能只比较“共同直径”。 | `NODE_DETAIL_REQUIRED`、`SECTION_RESIZE_RECOMMENDED` 或阻断；不以折弯主筋或未验证的多层筋强行消解冲突。 |
| G4 | **连续性和变更可审计** | 顶、底基础连续筋、共同支座的协调、附加筋截断、规格过渡和接头禁区优先于局部节省钢筋。当前“规格过渡”在锚固/搭接长度未确认前不得称为搭接合格。 | `SPLICE_UNVERIFIED` / `SPLICE_ZONE_PROHIBITED`；保持复核草稿。 |
| G5 | **施工便利性与项目偏好** | 仅对已通过 G0～G4 的方案排序：优先单层；再减小节点内最大主筋直径；再减少同一梁线的直径种类、端部区间距类别和不必要的规格变化；随后减少超出 G1 下限的面积与过强；最后才比较总根数、箍筋数量和项目优选钢筋目录。 | 若偏好与上层门禁冲突，忽略偏好并记录控制原因。 |

### ETABS 字段的角色

| 字段 | 角色 | 能否被自动减少 |
|---|---|---|
| `required`（纵筋、剪力、扭矩） | G1 的工程需求下限；须带站点、组合、单位和状态 | 否。 |
| `minimum` | 用于核对 ETABS 设计语义；不替代项目的 ACI/策略最小值 | 否。 |
| `provided` | 已确认时为默认自动运行的 no-decrease 基线，也是结果对比证据 | 否；仅在已授权的复核优化模式下可调整。 |
| `-1` / 空 `provided` | 不可用数据，不等于零 | 不适用；必须显示未确认。 |

## Consequences

- 当前选择器中“较少层数/较少根数/较大直径”的 tie-break 不得继续先于 G0～G4；算法需要改为先筛选、再按 G5 排序的确定性比较器。
- 工作簿、DXF 和 manifest 必须分别显示 `required`、`provided`、采用面积、控制站点/组合、使用的门禁和未确认项，避免把独立包络误读成单一荷载组合。
- `PB_SMF` 缺少设计体系证据、柱实际方向尺寸或容量剪力来源时，不得给出“施工图可用”结果。
- 本决策不把 ACI 318-14 最低要求等同于项目可施工性目标；批准后仍需由正式规范和工程签认维护条文映射。

## Required Validation Before Acceptance

1. `required`、`provided`、ACI 最小量和容量剪力同时冲突时，验证没有候选会低于控制下限。
2. `provided=-1`、空值、有效零值、`PARTIAL`、过期设计结果和未知单位分别产生不同且可追溯的状态。
3. 同一区段不同作用由不同站点/组合控制时，输出保留每个控制来源，且不生成虚假的“组合控制”。
4. `20d_b` 对 D20/D25/D28/D32、旋转柱及方向未解析均正确；最大穿节点直径变化会重新裁决。
5. 容量剪力大于 ETABS 原始 `VMajorArea` 时，横筋重新选择并按 `Vc=0` 复核；来源未验证则阻断。
6. 相邻跨协调改变钢筋后，所有受影响跨重新通过 G1～G3 和最终 `db` 箍筋检查；否则显式失败。
7. 多个均安全的候选验证 G5 的确定性排序：单层、较小节点最大直径、少规格、少变更、较少超强、较少根数。

## Alternatives Considered

- **沿用当前局部候选排序**：已有许多强度/净距测试，但不能明确保证读取值与节点可施工性优先于根数/直径偏好；不采用。
- **先最省钢筋再做校核**：会使安全和可施工性成为事后检查；不采用。
- **所有 ETABS 已提供面积都可自动优化**：在设计状态、模型一致性和节点能力未完全验证时可能静默减筋；不采用。

## Approval Required

结构负责人须确认 `provided` 的默认 no-decrease 语义、`20d_b` 的正式条文适用条件和容量剪力的项目取值后，才可将本 ADR 改为 `accepted` 并开始 `TASK-P1-010` 的代码实现。
